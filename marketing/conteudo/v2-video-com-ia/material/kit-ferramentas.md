## Setup para turma grande (10k+)

1. **Contas de demonstração** do instrutor, não dos alunos.
2. **Créditos reservados** para 3–5 gerações de Genjutsu e 3 avatares de exemplo.
3. **Cenas pré-renderizadas** para o caso de fila ou queda.
4. **Uma conta compartilhada** só para o exercício guiado; nunca peça login pessoal no chat.
5. **Plano B offline:** arquivos de exemplo na pasta do kit para quem não conseguir gerar.

## O que não prometer

- “Ilimitado” ou “grátis para sempre”.
- “Sem marca d'água” no plano gratuito.
- “Geração instantânea” no Genjutsu free.
- “Funciona em qualquer celular” para edição pesada.
- “Licença livre” para Remotion em qualquer empresa.
